# Hanguk — 한국 대학 입시 준비 앱

Hanguk은 우즈베키스탄 학생들이 한국 대학에 진학할 수 있도록 돕는
올인원 입시 준비 앱입니다. 지원 일정을 정리하고, 자기소개서를 AI와
함께 다듬고, 한국어로 진행되는 모의 면접을 연습하고, 한국 대학들을
지도에서 탐색해 보세요.

## 주요 기능

**맞춤형 학습 계획.** 지원할 대학을 선택하고 트랙(국문/영문 전형)을
설정한 뒤, 단계별 위저드가 빈 종이를 완성된 지원 전략으로 바꿔
드립니다. AI 피드백이 각 단계마다 누락을 잡아냅니다.

**자기소개서 작성, 더 빠르게.** 전용 작성 화면에서 실시간 문법 제안과
내용 피드백을 받아 보세요. 종합 점수도 즉시 확인 가능. 저장된 모든
드래프트는 자동으로 버전 관리됩니다.

**모의 면접 연습.** 한국어 원어민 AI 면접관과 대화하세요(친절형/엄격형/
조급형 페르소나 선택 가능). 세션이 끝날 때마다 녹취, 항목별 점수,
개선 사항 목록을 받습니다. 영어 모드도 지원합니다.

**한국 대학교 지도 탐색.** 캠퍼스를 탭하면 모집 일정, 모집 단위,
로드뷰 투어가 나타납니다. Kakao 지도로 정확하고 최신의 지리 정보를
제공합니다.

**상담사와 채팅.** 채팅 탭에서 컨설턴트와 바로 소통하세요.

## 사용 대상

한국 대학교 진학을 준비 중인 우즈베키스탄 고등학생. "한국에 갈까?"
하는 첫 고민부터 입학 허가서를 받기까지 모든 단계에서 유용합니다.
